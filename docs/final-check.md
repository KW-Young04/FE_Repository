# 최종 기능 점검 — 2026-11-12

## 판정

확인한 프런트엔드 오류는 수정했고, 빌드와 전체 ESLint를 통과했다. 다만 아래 미구현 기능과 실제 서버 통합 검증이 남아 있으므로 모든 기능이 완성됐다는 판정은 아니다.

## 실행한 검증

- `npm run lint`: 전체 통과. 점검 시작 시 오류 13건과 경고 1건을 정리했다.
- `npm run build`: TypeScript 및 프로덕션 번들 빌드 통과.
- `npm run test:smoke`: 실제 headless Chrome에서 54개 검사를 각각 1366×768, 1920×1080, 1180×600에서 통과했다.
- `git diff --check`: 공백 오류 없음.

브라우저 검사는 `tests/workspace-smoke.html`의 격리된 실제 React 컴포넌트와 실제 iframe 런타임을 사용한다. Git 및 파일 저장은 지연 응답을 직접 제어하는 가짜 API를 사용한다. 로그인된 전체 애플리케이션의 서버 통합 테스트를 대신하지 않는다. 스크롤 검사는 280px 컨트롤과 작업 화면 루트의 경계를 검증하며, 모든 실제 저장소 콘텐츠와 브라우저 확대 배율을 보장하지 않는다.

## 이번 점검에서 수정한 오류

1. Git 새로고침이 사용자의 파일 선택 해제를 취소하던 문제 및 중복 선택 경로.
2. 오래된 diff/상태 응답이 최신 선택을 덮어쓰던 문제와 diff 닫은 뒤 응답이 되살아나는 문제.
3. 같은 파일의 서버 저장 요청이 역순으로 완료될 수 있던 문제. 파일별 요청을 순서대로 처리한다.
4. 커밋·나가기 전 flush가 디자인에서 직접 시작한 저장 요청을 기다리지 않던 문제.
5. 수직 반전과 회전이 재선택 시 수평 반전으로 잘못 분해되던 문제.
6. 재선택 시 효과 강도가 항상 100으로 복원되던 문제.
7. 요소 미선택 상태에서 CSS의 pointer-events 차단만 적용되어 키보드 입력이 가능하던 문제.
8. 탭 전환·프리뷰 재로드·내부 경로 변경 후 오래된 디자인 선택이 남던 문제.
9. 디자인 메시지를 해당 프리뷰 iframe에서 온 것인지 확인하지 않던 문제.
10. 숫자 입력의 최솟값·최댓값이 입력값에 적용되지 않던 문제.
11. Git 데이터가 비어 있거나 조회에 실패했을 때 실제 데이터처럼 샘플 브랜치/커밋을 표시하던 문제.
12. 특정 파일명만 보고 가짜 AI diff와 작동하지 않는 적용/되돌리기 버튼을 표시하던 문제.
13. 클릭 동작이 없는 AI 수정 실행 버튼. 미지원 안내와 함께 비활성화했다.
14. 서버 요청 없이 메시지만 표시하던 채팅. 준비 중 안내와 함께 채팅/첨부를 비활성화했다.
15. 대비율 데이터가 없는 대체 텍스트 이슈에도 빈 대비율 카드와 잘못된 기본 색상 개선안을 표시하던 문제.
16. OAuth 실패 처리의 타이머 정리와 StrictMode 재실행, 주소창 상태 동기화, React 훅/모듈 분리 등 전체 lint 오류.

## 남아 있는 기능 누락

| 기능 | 현재 상태 | 필요한 작업 |
| --- | --- | --- |
| AI 자동 수정 | 미구현. 버튼 비활성화 | 수정 API 계약, 응답 코드 검토·적용·실패 처리 |
| AI 채팅·파일 첨부 | 메시지 서버 요청/첨부 처리 없음. 준비 중 표시 | 채팅/첨부 API 및 실제 답변·첨부 흐름 |

| 브랜치 생성·전환 | 탐색기 브랜치는 읽기 전용. 생성 콜백 없음. 커밋은 현재 브랜치에서만 가능 | API 및 변경 파일 처리·체크아웃·화면 갱신 흐름 |

| 터미널 | 로그 표시·프리뷰 재시작만 제공 | 명령 입력·프로세스 입출력 연결 |
| 디버그 | 세션이 없다는 안내만 제공 | 디버거 연결 기능 |
| 관련 가이드 | 이슈 코드/제목 텍스트만 펼침 | 실제 가이드 콘텐츠 또는 문서 연결 |

## 실제 서버에서 별도로 확인할 항목

실제 계정이나 원격 저장소를 변경하는 작업은 수행하지 않았다.

- GitHub OAuth 성공·실패·만료 토큰 및 로그아웃 후 API 인증 상태.
- 공개/비공개 저장소, 존재하지 않는 브랜치, 권한 거부, 네트워크 실패.
- WebContainer 설치·실행과 여러 실제 프로젝트의 프리뷰 탐색/재시작.
- 스냅샷 업로드 → 분석 결과 조회 → 재검사 → 이슈/점수 갱신 전체 흐름.
- 실제 파일 저장 후 커밋/푸시 성공·실패·부분 성공, 저장 실패 시 나가기 차단.
- 실제 콘텐츠·브라우저 확대 배율·장시간 연속 편집에서의 레이아웃과 저장 안정성.

프로덕션 빌드에 큰 청크 경고가 남아 있다. 빌드 실패는 아니며 성능 점검 시 코드 분할을 검토할 수 있다.
